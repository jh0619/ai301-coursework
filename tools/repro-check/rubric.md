# Rubric: is this reproduction package ready to post?

## Checks

| Check                               | Evidence                                                                                                                                | Pass condition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Weight   |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Claim is accurate and scoped        | Read the claim comment against the issue description.                                                                                   | Pass if the claim identifies the issue-specific behavior the contributor will investigate, promises to reproduce and report the result, and does not claim the bug is reproduced, promise a fix, or commit to a completion date before evidence exists.                                                                                                                                                                                                                                                                                                                                        | required |
| Environment is sufficient           | Read the repro report's environment record and the version or commit information listed in the package.                                 | Pass if the recorded repository revision and relevant operating system, runtime, application, dependency, and configuration details are sufficient for another contributor to recreate the environment. Require only details that could affect this issue.                                                                                                                                                                                                                                                                                                                                     | required |
| Steps are followable                | Read the repro report's setup instructions, commands, inputs, and referenced files in the order presented.                              | Pass if another contributor could recreate the same reproduction attempt without guessing an essential action or trigger condition. Exact file contents or byte-for-byte inputs are not required when the report describes the relevant characteristics clearly enough to construct an equivalent input. Fail if a missing command, input property, configuration, or setup action prevents the attempted behavior from being tested.                                                                                                                                                          | required |
| Evidence matches the issue          | Compare the issue's described behavior with the report's observed output, error message, stack trace, screenshot, log, or failing test. | For a report that claims successful reproduction, pass only if the artifact demonstrates the same behavior or failure mode described in the issue; an unrelated failure does not pass. For a cannot-reproduce report, pass if the contributor performs a relevant, good-faith attempt to exercise the reported scenario, includes evidence of the observed result, and explicitly identifies material environment or trigger differences that may explain the outcome. Fail if the attempt never reaches or tests the issue's target behavior, or if the included artifact is unrelated to it. | required |
| Outcome is stated honestly          | Compare the claim comment and repro report's conclusion with the included commands and artifacts.                                       | Pass if the conclusion says only what the evidence supports. An evidenced reproduction and an evidenced cannot-reproduce both pass. Fail if the report claims reproduction, a root cause, or another conclusion that the artifacts do not establish.                                                                                                                                                                                                                                                                                                                                           | required |
| Repository conventions are followed | Read the repo-facts contribution-policy block and applicable repository instructions against the claim comment and repro report.        | Pass if the comments follow all stated contribution and communication requirements. If the repository requires disclosure of AI assistance, the required disclosure must appear in the posted text. If no such disclosure rule exists, absence of a disclosure does not fail this check.                                                                                                                                                                                                                                                                                                       | required |

## Verdict rule

For a full reproduction package, return `accept` (`ready`) only if every required check passes. Return `reject` (`hold`) if any required check fails or is `unclear`.

For a claim-only draft, grade the claim and repository-conventions checks. Mark reproduction-only checks as not applicable and do not use them to determine the claim-only verdict.

An `unclear` grade on any applicable required check counts as failure because the package does not contain enough evidence to show that it is ready to post. Grade only the provided package and frozen repository evidence; do not assume missing information exists elsewhere.
